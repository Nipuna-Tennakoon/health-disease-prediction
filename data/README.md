# Data

Raw and cleaned data files are not committed to this repository.

## Download

1. Download the **Patient Health Record – Raw CSV** dataset from Kaggle: https://www.kaggle.com/datasets/mursaleen880/patient-health-record-raw-csv
2. Place `Patient_Health_Records_Raw.csv` in this directory, or run the download cell in `notebooks/01_visualization.ipynb`.

Target column: `Has_Disease`
